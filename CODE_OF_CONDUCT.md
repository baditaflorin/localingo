# Code of Conduct

We use the Contributor Covenant Code of Conduct, version 2.1.

## Our pledge

We pledge to make participation in this project a harassment-free experience for everyone.

## Expected behavior

Use welcoming language, respect differing viewpoints, accept constructive feedback, and focus on what is best for the community.

## Unacceptable behavior

Harassment, discriminatory language, personal attacks, publishing private information, and sustained disruption are not acceptable.

## Enforcement

Project maintainers may remove, edit, or reject contributions that do not align with this Code of Conduct.
