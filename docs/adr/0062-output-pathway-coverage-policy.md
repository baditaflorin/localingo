# 0062 Output Pathway Coverage Policy

## Status

Accepted

## Context

Users need more than one way to take their work out of the app.

## Decision

Support these output paths in Phase 3:

- downloadable JSON state
- clipboard export of state
- shared URL hash export
- visible activity log inside the app

Print/PDF and external API outputs remain out of scope for this release.

## Consequences

State movement is practical in a static-hosted product without over-claiming unsupported formats.
